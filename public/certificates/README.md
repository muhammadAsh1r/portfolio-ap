# Certificates Folder

Drop your certificate PDF files here!

### How to use them in the portfolio:
1. Place your PDF here, for example: `sample-certificate.pdf`
2. It will automatically be served at `/certificates/sample-certificate.pdf`
3. Update the `certificationsData` array in `src/components/Certifications.jsx` with the matching `pdfUrl: "/certificates/sample-certificate.pdf"`.
